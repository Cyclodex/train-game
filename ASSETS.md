# Asset inventory & provenance

Audited 2026-07-26. Resolved the same day.

> **The project ships no third-party assets.** Every pixel the game draws is
> generated by our own code. `src/assets/` no longer exists.

## How it got here

The audit found eight bitmap sprites — an engine shed and seven loco/wagon
PNGs — committed in December 2020 and January 2021, exported by Adobe ImageReady
(a tool discontinued around 2007) with no author, rights or credit metadata. They
were the only third-party content in the build, and their licence could not be
established. A ninth file, `railway-asssets.png`, was a 3.3 MB rasterised vector
sheet (Photoshop CC 2017, rendered from a PDF, document dated 2019) that the owner
recalled purchasing but could not locate an invoice for; nothing imported it, so
it never reached a build.

Rather than chase the paperwork, the sprites were **redrawn as SVG**
(`src/utils/trainArt.ts`, 2026-07-26) in the same procedural style as the rest of
the board, and every file in `src/assets/` was deleted:

| Removed | Replaced by |
|---|---|
| `depot.png` | `depotSvg()` in `utils/trainArt.ts` |
| `locomotivePeople.png`, `locomotiveFraight.png` | `locoSvg(kind, colour)` |
| `wagonPeople.png`, `wagonFraight1-4.png` | `wagonSvg(kind, colour, variant)` |
| `railway-asssets.png` | *nothing — unused reference sheet* |
| `logo.png`, `rail.svg`, `route.svg` | *nothing — dead since 2020* |

`railway-asssets.png` remains in **git history** (it was committed 2026-06-06 in
`0ead0a0`). It is not in the working tree and not in any build, but if this
repository is ever made public, purging it from history is worth doing first —
stock licences generally permit incorporating artwork into a product while
forbidding redistribution of the source artwork.

## What the game is made of now

- **Rolling stock and the engine shed** — `src/utils/trainArt.ts`
- **Rails and track geometry** — `src/tiles/geometry.ts`, `src/sim/pathGeometry.ts`
- **Roads, lane markings, kerbs, gores** — `src/tiles/roadGeometry.ts`
- **Terrain ground and scatter** — `src/tiles/terrain.ts`, `src/utils/foliage.ts`
- **Backdrop** — `src/utils/meadowBackdrop.ts`
- **Signals, switches, crossings, vehicles, HUD** — SVG and CSS in the components

The only binary left in the repository is `public/favicon.ico` from the `vue-base`
starter, plus our own `npm run shot` screenshots under `docs/verify/`.

**No fonts are bundled.** Typography uses system stacks only
(`ui-sans-serif, system-ui, -apple-system, "Segoe UI"`); the single `@font-face`
in `src/scss/global/_typography.scss` is commented out, and there are no CDN or
Google Fonts references.

## Still open

1. **The `vue-base` starter's licence.** `README.md` is still the starter's, there
   is no `LICENSE` file, and `package.json` is `"private": true` with no `license`
   field. Establish what the scaffolding permits, then add a licence for our code.
2. **Record any future asset here on the way in**, with source and licence — or
   better, keep drawing them. The current position (zero third-party assets) is
   worth defending: it is what makes the project free to sell, open-source or give
   away without a paperwork trail.
