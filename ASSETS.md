## What the file metadata suggests

There appear to be **three separate provenance questions**, not one.

### 1. The eight sprites that actually ship ← the one that matters

`depot.png` and the seven loco/wagon PNGs, committed Dec 2020 – Jan 2021. All
eight carry `tEXt Software = Adobe ImageReady` — a tool discontinued around 2007,
so these were exported by an old pipeline and are **almost certainly not slices of
the 2026 pack** below. No author, rights or credit fields survive in any of them.

**These are the files a commercial release would distribute**, so their licence is
the blocking question.

### 2. `railway-asssets.png` — the purchased pack, currently unused

2000×9954, 3.3 MB, added 2026-06-06 with the commit message "assets". Matches the
top-down railway vector sheet the owner remembers buying (rolling stock, road
vehicles, buildings, crossings, track pieces, hedges).

XMP metadata:

- `xmp:CreatorTool = Adobe Photoshop CC 2017 (Windows)`
- `xmpMM:RenditionClass = proof:pdf` → rendered **from a PDF**, which is how stock
  vector packs are usually delivered (AI/EPS/PDF)
- `xmpMM:DocumentID = adobe:docid:photoshop:66ad4b9b-b9c3-11e9-…` → the `11e9`
  UUID field dates the document to **2019**
- `xmpMM:OriginalDocumentID = uuid:5D20892493BFDB11914A8590D31508C8`
- No `dc:creator`, `dc:rights`, `photoshop:Credit` or `Source` — stripped

So: a 2019-era commercial vector pack, rasterised from the delivered PDF. Nothing
in the file identifies the marketplace.

**Note the redistribution angle.** Even though it does not ship in the build, the
sheet *is* committed to git history. Most stock licences permit incorporating
artwork into a product but forbid redistributing the source artwork as-is — which
is roughly what a public repository containing this file would be doing.

### 3. Starter scaffolding

`logo.png` (XMP dates it to 2015, arrived in the *Initial commit*) and
`public/favicon.ico` come from the Emergency Room team's `vue-base` starter, along
with the project scaffolding. `README.md` is still the starter's, and the repo has
**no LICENSE file**; `package.json` is `"private": true` with no `license` field.
The starter's terms are unknown.

## What is unambiguously ours

Most of what the game currently draws is **generated by our own code**, not by any
asset file: rail and road geometry (`tiles/geometry.ts`, `tiles/roadGeometry.ts`),
the meadow backdrop (`utils/meadowBackdrop.ts`), terrain ground and foliage
(`tiles/terrain.ts`, `utils/foliage.ts`), signals, switches, crossings, cars and
all HUD chrome (SVG/CSS in the components). The licensing surface is therefore
small — eight sprite files — and has been shrinking as procedural art replaced
bitmaps.

**No fonts are bundled.** Typography uses system stacks only
(`ui-sans-serif, system-ui, -apple-system, "Segoe UI"`, and an `Avenir, Helvetica,
Arial` fallback); the one `@font-face` in `src/scss/global/_typography.scss` is
commented out, and there are no CDN or Google Fonts references anywhere.

## Open actions

1. **Find the invoice for the 2019 railway pack.** Search purchase email around
   2019 and around June 2026 for the usual marketplaces: Adobe Stock, Shutterstock,
   Freepik, Envato / GraphicRiver, VectorStock, iStock, Depositphotos, Creative
   Market. The delivery format was PDF/vector.
2. **Establish where the eight shipping sprites came from** — they predate the pack
   by five years and are the actual blocker. If their origin cannot be established,
   the safe move is to **redraw or replace them** from a source with a known
   licence. They are eight files; this is a day of work now and a much worse
   problem later.
3. **When the licence is found, check four things specifically**, because stock
   licences differ exactly here:
   - use in a **commercial product sold to end users** (usually permitted);
   - whether an **extended / multi-use licence** is required when the artwork is a
     core component of a product for sale (Envato and Shutterstock draw this line);
   - **attribution** requirements (Freepik's free tier requires it; paid tiers often
     do not);
   - **redistribution of the source artwork**, which bears on keeping
     `railway-asssets.png` in git history and on any public repository.
4. **Resolve the `vue-base` starter's licence**, and add a `LICENSE` file for our
   own code once it is known what the scaffolding permits.
5. **Delete or relocate the unused files** — `logo.png`, `rail.svg`, `route.svg`
   are dead, and `railway-asssets.png` is a 3.3 MB reference sheet that belongs in
   a working folder outside the repo rather than in git history. (Removing it from
   *history*, as opposed to from `HEAD`, needs a rewrite — worth doing before the
   repo is ever made public, not after.)
6. **Record every future asset here on the way in**, with source and licence. The
   cost of this audit scales with the number of files; keeping it current is
   minutes per asset.
